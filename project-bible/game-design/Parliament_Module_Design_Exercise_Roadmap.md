# Parliament Module Design Exercise — Non-Canonical Roadmap

> **Authority boundary — NON-CANONICAL DESIGN EXPLORATION.** This mutable roadmap plans an exercise; it does not perform one or accept its possible results. It is a working-model aid, not an accepted gameplay contract, Architecture Decision evidence, Governance authority, WP-008 closure evidence, approval evidence, or a replacement for GD-100. Detail and ordering do not imply design acceptance.

## 1. Purpose

The Parliament Module is the planned first concrete stress test of the [Political / Institutional Gameplay Working Model](Political_Institutional_Gameplay_Working_Model_Exploration.md). The exercise should expose weak boundaries and player-experience gaps before any explored model becomes canonical.

This roadmap deliberately does **not** design all areas below, define a universal Parliament, or hardcode parliamentary rules. Each result remains subject to collaborative exploration and concrete gameplay testing.

## 3. First planned gameplay stress test

### Project concept

**Introduce a New National Tax**

Purpose: test the tentative Authority model and Parliament Module through concrete player interaction. The future exercise should compare at least two substantially different institutional states while keeping the underlying Project concept equivalent.

Expected conceptual flow:

```text
Project
  → Authority Requirements
  → State Configuration
  → Authority Path
  → Institutions
  → Actors / Support
  → Player Actions
  → Decision
  → Implementation Capacity
  → World Reaction
  → New State
```

This note does **not** select the compared states, resolve an Authority Path, assign Actors or values, simulate outcomes, or finalize the mock gameplay.

### Questions for the click-by-click exercise

The next collaborative design activity should answer:

- What does the player see?
- What does the player choose?
- Which Authority is required?
- Which Institution owns each Authority step?
- Which Actors matter?
- Where can the player intervene?
- What Actions become available?
- What can block the Project?
- Can the player bypass the normal Authority Path?
- What happens if they do?
- How do Support, Legitimacy, Capacity, and Control affect the process?
- How does implementation occur?
- What autonomous reactions follow?
- How does the resulting world state create the player's next political problem?

## 4. Success criterion for the future exercise

The exercise should test whether an equivalent abstract Project can yield legible, strategically different play through different State Configurations, without turning government forms into modifier bundles or hardcoding the Project to Parliament. It should reveal needed revisions and open questions; it is not intended to prove the entire political engine.

## 5. Promotion boundary

Exercise output will remain exploratory unless deliberately reviewed and migrated into an authorized gameplay contract. This roadmap is not evidence that WP-008 is complete, that GD-100 has changed status, or that any political concept has been approved.
